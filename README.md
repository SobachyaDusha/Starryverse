# Starryverse — artist archive & portfolio with Supabase

Starryverse is a web archive/portfolio prototype with galleries, characters, timeline, notes, search and an admin workflow. The project connects a static frontend with Supabase services for authentication, database storage, file storage and realtime updates, while keeping an IndexedDB fallback for offline/local behaviour.

## My role

The project was built mainly with AI coding tools. I defined the product structure and behaviour, described features step by step, tested generated versions, reproduced UI/data bugs and guided fixes through repeated iterations.

I do **not** present the code as fully handwritten by me. This repository is a case study in AI-assisted web prototyping, integration testing and iterative debugging.

## Main features

- portfolio/archive home page;
- character pages and gallery;
- timeline, lore and notes;
- search and settings;
- admin authentication and content workflow;
- Supabase Postgres/Auth/Storage integration;
- realtime updates;
- IndexedDB fallback for selected offline data.
